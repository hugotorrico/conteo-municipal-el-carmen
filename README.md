# Conteo Municipal El Carmen

Aplicación web colaborativa para registrar el conteo no oficial por mesa de la Municipalidad Distrital de El Carmen (Chincha, Ica).

- 38 mesas precargadas.
- Registro de personero y número visible de mesa.
- Votos por candidato, blancos y nulos.
- Porcentajes sobre votos válidos.
- Dashboard y resumen por local.
- Enlaces de edición por mesa mediante token.
- PIN de administrador para editar todas las mesas y generar enlaces.
- Persistencia compartida con Vercel Blob.

> Herramienta de conteo local no oficial. No reemplaza los resultados de los organismos electorales.
